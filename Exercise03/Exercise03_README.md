# Exercise 3 — Reasoning Model Reports

## Prompt (used on all three)
> Generate a detailed report on how you can use generative AI as a university student to learn subjects like probability and statistics, database management systems, and software engineering.

## Models Used

| Model | Site | Mode | Output |
|---|---|---|---|
| DeepSeek | https://chat.deepseek.com | DeepThink R1 | Typed in chat — see `DeepSeek_R1_report.md` |
| Qwen | https://chat.qwen.ai | Thinking | Typed in chat — see `Qwen_Thinking_report.md` |
| Grok | https://x.com/i/grok | DeepSearch | Returned as a PDF — attach separately |

## Reflection

All three models produced solid, well-structured reports covering the same core ground — prompt strategies, subject-specific use cases, and academic integrity warnings. DeepSeek's DeepThink R1 and Qwen's Thinking mode were very close in depth and organization, both typed directly in chat with clear section breakdowns. Grok's DeepSearch stood out by exporting a polished, longer PDF report with a references section and more structured formatting (table of contents, page numbers), likely because DeepSearch pulls in and synthesizes external sources rather than generating purely from the model itself. Overall, Grok's DeepSearch gave the most comprehensive and publication-ready result, while DeepSeek and Qwen were faster and more concise for quick reading.
